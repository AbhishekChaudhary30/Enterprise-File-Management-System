# Enterprise File Management System

A production-style desktop application developed using Python for managing and organizing files efficiently. The project follows a modular architecture and demonstrates software engineering practices such as object-oriented programming, clean code organization, database integration, logging, and testing.

---

## Overview

Enterprise File Management System is designed to simplify common file management tasks through a single desktop application. Instead of manually searching, organizing, or managing files, the application provides dedicated tools to perform these operations quickly and efficiently.

The project was built with the goal of practicing real-world software development by focusing on maintainable architecture, modular design, and production-oriented coding practices rather than only implementing individual features.

---

## Features

- Recursive file scanning
- Smart file search
- Duplicate file detection
- File organization by extension
- Backup creation
- Report generation
- Recycle Bin management
- Undo / Redo support
- Operation history
- Modular architecture

## Installation

```bash
git clone https://github.com/AbhishekChaudhary30/Enterprise-File-Management-System.git

cd Enterprise-File-Management-System

python -m venv .venv

.venv\Scripts\activate

pip install -r requirements.txt

python main.py
```
